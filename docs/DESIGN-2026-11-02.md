# Redesign da página de links

## Referências

- `IMG_6590.JPG`: grade modular, azul e lima, linhas pretas e índices numerados.
- `IMG_6577.JPG`: cartões de links com moldura de janela e sombra dura.
- As referências serviram só de inspiração. Nenhuma marca, logotipo ou ilustração foi reproduzida.

## Tokens

| Token | Valor |
|---|---|
| Papel | `#F4F3EC` |
| Cartão | `#FFFEF9` |
| Tinta e borda | `#171717` |
| Texto secundário | `#505050` |
| Azul | `#1746E8` |
| Lima | `#D9FA45` |
| Tipografia de títulos | Barlow Condensed 600/700 |
| Tipografia de interface | IBM Plex Mono 400/500 |
| Espaçamento | escala curta de 4, 8, 10, 14, 16, 18, 20 e 24 px; margens maiores de 28, 38 e 48 px |
| Raios | 0 px; cantos quadrados |
| Sombra dos cartões | 4 px, deslocamento preto sólido |

O tema escuro do sistema também é preservado com versões de alto contraste dos mesmos tokens. No tema claro, as razões de contraste calculadas são 16,12:1 para tinta/papel, 7,25:1 para texto secundário/papel, 6,82:1 para branco/azul e 15,93:1 para preto/lima. Os controles têm pelo menos 44 px de altura; os cartões inteiros são clicáveis e há foco visível para teclado.

## Decisões

- A página continua como uma folha única, com o nome e os dados atuais no cabeçalho.
- Contato, Ferramentas, Projetos e Apoio formam os módulos `01/` a `04/`. Os cartões receberam uma barra de janela, numeração e sombra dura.
- A grade usa duas colunas nos cartões em telas estreitas e se reorganiza em módulos assimétricos no desktop.
- O Pix continua usando a chave e o mecanismo de cópia existentes.
- A saída estática em `public/` foi atualizada junto com a página Astro.

## Não foi feito

- Não alterei `src/links.ts`, nomes, descrições, URLs ou a chave Pix.
- Não acrescentei conteúdo, destinos, integrações ou dependências.
- Não copiei ilustrações ou marcas das referências.
- Não removi o shim de vidro em `src/glass/`; apenas deixei de usá-lo nesta página.
